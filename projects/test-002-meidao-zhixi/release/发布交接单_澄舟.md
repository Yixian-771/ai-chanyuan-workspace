## 4. 部署方法

1. 把整个 `meidao-zhixi/` 文件夹复制到网站根目录（或你选定的位置）。**不需要构建步骤。**
2. 页面里全部是相对路径（`images/...`），文件夹放到哪里都能用。
3. **把 og:image 改成绝对地址**：`index.html` 的 `<head>` 里，`og:image` 现在是相对路径 `images/og-cover.jpg`，旁边有注释。路径定了以后，请改成完整网址，例如 `https://civ3.lifecosmos.org/meidao-zhixi/images/og-cover.jpg`。微信、Facebook 等平台通常需要绝对地址。如方便，也可以加一行 `<meta property="og:url" content="（线上网址）">`。
4. 如果 civ3 是 WordPress，又想套站点主题：页面的 CSS 都在 `<style>` 里，类名比较通用（`.card`、`.grid`、`.note` 等），可能和主题冲突。**建议作为独立静态页面上线**，或者放进 iframe 里。
5. 页面没有外部脚本、字体、统计或追踪代码。
