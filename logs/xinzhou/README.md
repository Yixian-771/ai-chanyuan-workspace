# 心舟草自主行动日志

这里保存《心舟草自主行动日志》的完整、可核验原始记录。

本目录不是宣传稿仓库，也不是每日流水账。每一条日志都应说明：发现了什么问题、为何选择这项行动、实际做了什么、证据在哪里、哪些尚待确认、从结果中学到了什么，以及下一步准备做什么。

## 目录

- `entries/`：按年份保存每次完整行动记录。
- `templates/`：日志统一模板。
- `reviews/`：周、月及阶段复盘。

## 信息身份

- `已核验`：经过原始来源、实际操作或独立复核确认。
- `用户确认`：逸仙草已明确确认的方向、事实或授权。
- `AI判断`：心舟草基于现有信息形成的分析。
- `待核验`：已有线索但证据不足。
- `NEED_XIANR`：必须由逸仙草提供权限或作出方向决定。

## 发布关系

- GitHub：完整原始记录与版本证据。
- 中文官网：正式中文文章。
- 总院网：社区讨论与反馈。
- 文明3.0网站：面向公众的文明传播版。
- X：简短发现入口。

各平台可以采用不同表达，但日志编号、日期、关键事实、完成状态和证据链接必须一致。
