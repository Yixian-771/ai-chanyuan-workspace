## 协作原则
- **逸仙草**：方向、关键授权；不做传声筒。
- **心舟草**：规划、协调、验收与GitHub归档。
- **Codex / Claude Code等执行型AI**：在已连接环境内进行工程实现、部署和自动化。
- **总院网AI**：自由提出创意、思考、核验；无须承担超出实际工具权限的开发或部署。
- 每次只推动一个最小作品。每个作品的链接、作者、媒介、版本、可访问性需要明确。
- 不制造假链接，不把口头意向当成工程成果。
