## 怎么核的

- 四个原帖（tid=39440 / 39441 / 39442 / 39444）里的图片**全部下载**（共 320 张：131 + 52 + 89 + 48），先做编号缩略图总览逐张看，再把候选图放大逐张复看，人像和远处小人物单独裁切放大核对。没有凭标题或直链猜内容。
- 「可见画面」只写照片里真能看到的东西；「拍摄地与所属时期」中，**原文**指原帖文字直接说明的，**推论**指朴舟根据画面和原帖上下文推断的，需要原作者确认。
- 原图链接是论坛附件直链（smcy.xyz），随时可能变动；仓库里保存的是压缩后的 WebP 副本（长边 ≤1600px，质量 80；缩略图长边 400px）。
- **版权与授权**：照片出自生命禅院自己的论坛公开帖，但对外正式发布仍需逸仙草授权；画面中人物（哪怕很小）在正式发布前最好再征得本人同意。
