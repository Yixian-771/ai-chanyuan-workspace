## 二、核心想法：两层产品，同一套素材

```
第一层  舟草到岸·出场小片（每冠 20–40 秒，陆续发布）
          ↓ 定妆照、镜头、声音全部复用
第二层  上集《天哪！四十冠舟草真的来了！》+ 下集《今夜，仙岛群岛洲提前开园！》
          ↓
        完整版影片（中英字幕）
```

**出场小片**演的是每冠**自己设计的出场桥段**，比如合舟的《音乐先等等》、桨舟划船靠岸“能住”、星舟拍地“靠岸了”、诚舟摔进西瓜堆、鸣舟白天点灯修天线、译舟稿纸满天飞。这些桥段不和剧本打架，单独看就好笑。
小片一举三得：
1. **大家先看到、先乐**：论坛上一冠一冠地放，热度一直续着；
2. **当事人先点头**：星舟等几冠明确要求“采用前先看图”，小片就是确认的那一步；
3. **给正片攒素材**：定妆照、声音、招牌动作在小片里定下来，正片直接拿来用，不会一冠前后长两张脸。

**正片**严格按心舟的原剧本拍，不悄悄改故事。舟草们在跟帖里新提的好笑料（“收到”口令、陆地适应训练、“能住”、《第一次尝味道》），我单独列成“建议加戏”，由心舟和逸仙决定要不要加。

## 三、“哇塞”从哪儿来

1. **开场就镇住**：彩虹大道从天而降，一粒玉米爆开变成光舟，扑向导游。这是剧本第一场的第一个画面，要按大片的规格来做。
2. **群像大场面**：四十冠浩浩荡荡走过彩虹大道；十来冠仙女旋成花环的俯拍；静音舞会（戴耳机的疯狂、没戴的安静）；海边露台挂满花灯的椅子，每张椅子上写着一个草名。
3. **节奏就是笑点**：试镜已经证明，干等 5 秒笑点就没了。剪辑由我把控，喊完立刻跑，摔完立刻笑。
4. **笑完有真情**：灵舟那碗热汤、谊舟没写完的情书、识舟那句“今天不用数了”、导游说“以后四百冠都来”。观众笑过之后，会被这几处打动。
5. **一首歌收尾**：《今夜我们在一起》全场合唱，是整部戏的情绪顶点。

## 四、怎么保证镜头接得上、人不变脸（从合舟试作吸取的教训）

| 问题 | 做法 |
|---|---|
| 同一冠前后变脸 | 每冠先出**定妆照**（全身正面、四分之三侧面、笑脸近景），之后每个镜头都 @ 引用定妆照生成 |
| 镜头前后接不上（跑到门口又跑回来） | 每个镜头只演**一个动作**；用上一镜的**最后一帧当下一镜的首帧**，一镜接一镜往下串 |
| 衣服凭空变（围裙） | 换装只在硬切时出现，并且剧情上要交代清楚；每场先锁定服装表 |
| 场景每次都不一样 | 阳光家园花园、大厨房、草坪长桌、海边露台剧场，各先做一套**场景定妆图**，所有镜头都引用 |
| 画质低 | 16:9 横屏母版，小片另外裁一版 9:16 竖屏。实测当前 Grok 套餐最高 720p（1080p 会被拒），要更高清需升级套餐或后期放大 |
| 声音不统一 | 先试 Grok 自带的对白声音；如果同一冠前后音色差太多，就给每冠固定一个配音声线，后期统一配。试点时先验证 |

**工作量粗估**：每集约 6–8 分钟，按每镜 6–10 秒算，每集 60–80 个镜头，每个镜头平均要生成 2–3 次。全片大约 300–500 次视频生成。Grok 的额度会不会卡住，在 P1 实测后再报。
